# PDFHub

Сайт с инструментами для PDF на Next.js 15 (App Router). Интерфейс на русском.

## Запуск в продакшене (рекомендуется: Docker)

Все инструменты работают «из коробки», потому что в образе уже установлены LibreOffice, qpdf, Ghostscript и шрифты.

```bash
cp .env.example .env          # задайте NEXT_PUBLIC_SITE_URL, при желании ANTHROPIC_API_KEY
docker compose up -d --build  # сайт: http://localhost:3000
```

С HTTPS на своём домене (Caddy получает сертификат сам; DNS домена должен указывать на сервер):

```bash
echo "DOMAIN=example.com" >> .env
docker compose --profile https up -d --build
```

- Данные (аккаунты, сообщения) лежат в томе `pdfhub-data` — делайте его резервную копию.
- Проверка состояния: `GET /api/health` показывает, какие программы доступны на сервере.
- Нужен минимум 2 ГБ ОЗУ (LibreOffice). Лимиты: `MAX_UPLOAD_MB`, `MAX_CONCURRENT_JOBS`.
- Если стоите за своим nginx, поднимите `client_max_body_size` до 60m.

## Запуск без Docker

Нужны Node 20+ и программы: LibreOffice, qpdf, Ghostscript.

- Linux: `sudo bash setup-linux.sh`
- Windows: запустите `setup-windows.ps1` (через winget поставит LibreOffice, qpdf и Ghostscript) или установите их вручную. Сайт сам находит их в `C:\Program Files`; если установлены в другое место — задайте `SOFFICE_PATH`, `QPDF_PATH`, `GS_PATH` в `.env`.

```bash
npm install
npm run dev                    # разработка
npm run build && npm start     # продакшн
```

Если какой-то программы нет, сайт автоматически использует упрощённый вариант в браузере (качество ниже), а `/api/health` покажет, чего не хватает.

## Что умеет

| Группа | Инструменты | Где работает |
|---|---|---|
| Организация | Объединить, Разделить, Удалить страницы, Извлечь страницы, Упорядочить, Сканировать в PDF | браузер |
| Оптимизация | Сжать (сильное/максимальное — браузер, лёгкое — сервер), Восстановить (qpdf), OCR (Tesseract.js) | смешанно |
| В PDF | JPG→PDF (браузер); WORD, POWERPOINT, EXCEL, HTML→PDF (LibreOffice) | смешанно |
| Из PDF | PDF→JPG/PNG, PDF→EXCEL (браузер); PDF→WORD, PDF→POWERPOINT, PDF→PDF/A (LibreOffice) | смешанно |
| Редактирование | Повернуть, Номера страниц, Водяной знак, Обрезать, Редактировать, Формы | браузер |
| Безопасность | Разблокировать, Защитить (qpdf, AES-256); Подписать, Скрыть данные, Сравнить | смешанно |
| Умные | ИИ-резюме, Перевод (Claude API); PDF→Markdown (браузер) | смешанно |

Браузерные инструменты не отправляют файл на сервер. Серверные (`/api/convert`, `/api/qpdf`) пишут файл
во временную папку и удаляют сразу после ответа. «Резюме» и «Перевод» отправляют **текст** документа на сервер и в Claude API.

## Сайт целиком

- Шапка: быстрые инструменты, выпадающий список «Конвертировать PDF», меню «Все инструменты», вход/регистрация, меню «Ещё» (бизнес, приложения, цены, безопасность, возможности, о сервисе, помощь).
- Страницы: `/pricing`, `/features`, `/business`, `/contact`, `/help/faq`, `/help/security`, `/help/about`, `/help/documentation`, `/help/legal`. Тексты лежат в `lib/site.js` — отредактируйте под себя (особенно «Конфиденциальность и условия»: добавьте данные оператора).
- Аккаунты: `/register`, `/login`, `/account`. Пользователи хранятся в `data/users.json` (пароли — scrypt, сессия — подписанный HttpOnly-cookie). Это простое файловое хранилище для одного сервера; для нескольких серверов замените `readUsers/writeUsers` в `lib/server/auth.js` на свою БД. Папку `data/` нужно сохранять между перезапусками (в Docker: `-v pdfhub-data:/app/data`).
- Контакты: сообщения пишутся в `data/messages.jsonl` (и в `CONTACT_WEBHOOK_URL`, если задан).
- Сайт можно установить как приложение (PWA): есть `manifest` и иконки.
- Язык интерфейса — только русский (переключателя языков нет).

## Настройка (`.env`)

- `NEXT_PUBLIC_SITE_URL` — адрес сайта (для sitemap и мета-тегов).
- `AUTH_SECRET` — секрет для подписи сессий. Если не задан, создаётся случайный и сохраняется в `data/secret.key`.
- `DATA_DIR` — где хранить `users.json` и `messages.jsonl` (по умолчанию `./data`).
- `CONTACT_WEBHOOK_URL` — необязательно: куда дополнительно отправлять сообщения из формы «Контакты».

- `ANTHROPIC_API_KEY` — необязательно. Без ключа «ИИ-резюме» делает встроенный алгоритм, а «Перевод» идёт по цепочке: Claude (если есть ключ) → LibreTranslate (если задан `LIBRETRANSLATE_URL`) → бесплатные сервисы Google и MyMemory. Серверу нужен выход в интернет.
- Видео/аудио (ffmpeg), HEIC и EPUB работают сразу после `npm install` — нужные модули ставятся вместе с проектом. LibreOffice и qpdf нужны для Office/PDF-инструментов (Docker или `setup-windows.ps1`/`setup-linux.sh`).
- `ANTHROPIC_MODEL` — модель (по умолчанию `claude-sonnet-5-5`).
- `MAX_UPLOAD_MB` — лимит размера файла для серверных инструментов (50).
- `MAX_CONCURRENT_JOBS` — сколько конвертаций одновременно (2).

## Известные ограничения

- PDF→WORD/POWERPOINT через LibreOffice: простые документы получаются хорошо, сложная вёрстка может поплыть. PDF→EXCEL ищет таблицы по расположению текста; сканы сначала нужно пропустить через OCR.
- OCR при первом запуске скачивает языковые данные Tesseract с CDN (нужен интернет в браузере).
- «Скрыть данные» превращает затронутые страницы в изображения — скрытый текст удаляется из файла безвозвратно, но на этих страницах пропадает выделение текста.
- «Редактировать PDF» добавляет объекты поверх страниц, но не правит существующий текст.
- Подпись — графическая картинка, а не квалифицированная электронная подпись.
- Шрифт для добавляемого текста — DejaVu Sans (есть кириллица); лежит в `public/fonts`.

## Структура

- `lib/tools.js` — реестр инструментов (добавить инструмент = добавить запись + операцию в `lib/ops.js`)
- `lib/ops.js` — операции в браузере (pdf-lib, pdf.js)
- `app/api/*` — серверные обработчики
- `components/*` — интерфейс
